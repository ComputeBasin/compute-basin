# Landing Page

Nuova UX:
- Home con tab `Pool terreni` e `Affitta potenza computazionale`
- Admin dashboard (accesso solo wallet admin)
- Proof viewer tecnico

## Flusso utente

1. Wallet participant compra token nelle pool.
2. Gli stessi token sono usati per noleggiare potenza compute su siti operativi.

## Setup

```bash
cp .env.example .env
npm install
npm run dev
```
